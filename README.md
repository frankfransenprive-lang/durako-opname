# Durako Opname — iPhone uploadversie

Deze versie is speciaal gemaakt zodat ALLE bestanden in de hoofdmap van GitHub mogen staan.

Upload deze 7 bestanden rechtstreeks naar de hoofdmap van `durako-opname`:

- package.json
- server.js
- index.html
- README.md
- main.jsx
- styles.css
- wadCatalog.js

Er zijn geen `src`-mappen nodig.

## Railway
Build command: `npm run build`
Start command: `npm start`

Let op: als GitHub op iPhone bestanden hernoemt naar bijvoorbeeld `package 2.json`,
verwijder dan de oude versie eerst of kies bij upload voor vervangen indien GitHub dat aanbiedt.
